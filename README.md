# Portfólio

Portfólio de Cinthia Dutra, publicado como uma página HTML estática no GitHub
Pages.

## Conteúdo

- [Abrir o portfólio](./index.html)
- [Baixar a versão em PDF](./Cinthia-Dutra-Portfolio.pdf)

O conteúdo principal está em HTML e CSS, sem dependências externas. O arquivo
PDF continua versionado como uma versão alternativa para download.

## Publicação

Nas configurações do repositório, selecione **Settings > Pages > Deploy from a
branch**, escolha a branch `main` e a pasta `/ (root)`. O GitHub Pages usará o
`index.html` como página inicial.
